AquaticPrime Manager

  • AquaticPrime Manager

Manage and EMail your AquaticPrime Licenses

AquaticPrime Manager is an application which will help you to manage your AquaticPrime licenses. The application builds upon the default folders created by AquaticPrime Developer which is the appication included in the AquaticPrime sources and download.

AquaticPrime Manager goes far beyond the simple application and provides many more useful functions.

Download Here

Features

  • Internal EMail functions which permit sending licenses directly to user from the application.
  • Search for existing licenses by any key value.
  • Migrate license data to MySQL database.
  • Synchronize local licenses with MySQL database.

Usage


The application assumes a certain folder structure in the Finder. On intial startup, AquaticPrime Manager will look for the folder ~/Library/Application Support/Aquatic created by the old AquaticPrime Developer program. If the folder exists, you will be asked if you want to move its content to the new AquaticPrime Manager folder.
AquaticPrime Manager follows the folder structure as defined in the AquaticPrime Developer application. The application will create a support folder in your library folder which contains the product information and a copy of each generated license.
AquaticPrime Manager will also permit you to store licenses for each product in a seperate License folder. In effect, the License folder contains a duplicate of the licenses in the Generated Licenses folder in the support folder.

he default location for product license files is in your home Documents folder.

I recommend you create a single Licenses folder somewhere appropriate for your situation and then create your individual product license folders inside the Licenses folder as in the example.

If you have more than one hard drive available I highly recommend you setup this folder on a different drive than the one where your home folder is located.
Each product License folder will contain a set of three folders as in this example.

Attachments Folder


The attachments folder is where you will store the email body text and optional email picture file along with any other file you wish to be attached to the email sent to the user for the product.
The Attachments folder must contain at least one file which is the text used for the license body. The image file and other attachment file are optional.

Email Body File

This is a required file, in it, you can specify instructions to the user, etc. If you desire to use the image file for the body, simple leave the file blank, but it must be present.
